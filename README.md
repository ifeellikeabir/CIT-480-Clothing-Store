# CIT-480-Clothing-Store
This is our CIT 480 clothing store website project 

MySQL Server Download:
https://dev.mysql.com/downloads/mysql/

Create a new file named " .env" and leave it in the root of the project folder
Paste the following:

PORT=3000
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=CIT480_db * this may very, will need to test
DB_NAME=wardrobe_db * this may very, will need to test

Create a new file named ".gitignore" and leave it in the root of the project folder
Paste the following:

.env
node_modules/

Launch terminal/command prompt and run these commands:

 npm install
 npm start        (same as: node server.js)

Then open the site at: http://localhost:3000
(server.js now serves the website too, so the pages and the database run together.
Keep that terminal open while you work. Refresh the browser to see your changes.
If you change server.js, stop it with Ctrl + C and run npm start again.)
